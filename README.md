# PDFひとまとめ

ブラウザで写真をPDFに変換し、複数のPDFを1つに結合できる静的サイトです。

- **写真をPDFに** — JPG・PNG・WebPを選択し、1枚ずつA4のページに変換します。画像の向きに合わせてページの縦横を選び、出力用の画像に元のEXIF情報を含めません。
- **PDFを結合** — 2つ以上のPDFを一覧の順に結合します。ファイル名、文書タイトルや作成日時などの文書情報を除き、結合に使うページデータが一致するPDFは一度だけ追加します。パスワードで保護されたPDFは対象外です。
- どちらの機能も、ファイルの追加・並べ替え・削除ができます。
- PDF結合の「重複ページを除く」をオンにすると、同じページデータが複数回出てきたとき、最初の1枚を残します。すべてのページを残すにはチェックを外してください。
- ファイルは端末のブラウザ内で処理します。サイトに外部サービスへの送信やアクセス解析は組み込んでいません。

## 起動

`index.html` をブラウザで開きます。ビルドや依存関係のインストールは不要です。

GitHub Pagesに載せる場合は、リポジトリの **Settings → Pages** で **Deploy from a branch** を選び、`main` と `/(root)` を指定します。利用できる公開設定はGitHubのプランに依存します。

PDF処理には同梱の pdf-lib 1.17.1 を使用しています。ライセンスは `vendor/LICENSE.md` にあります。
